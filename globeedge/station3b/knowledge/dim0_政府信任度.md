# dim0 政府信任度 — PTT 語境知識

## 台灣在地政治術語
- 「執政黨」：目前指民進黨（2024-至今賴清德）
- 「在野黨」：國民黨、民眾黨
- 「1450」：PTT 用語，指涉網軍或被認為替執政黨護航的帳號
- 「側翼」：被認為幫執政黨帶風向的 KOL 或媒體
- 「覺青」：覺醒青年，可褒可貶，偏向支持進步派
- 「塔綠班」：嘲諷民進黨支持者的用語

## 真誠批評政府範例
1. 「賴清德的能源政策根本沒有解決缺電問題，電價漲了三次了」
   → 語氣：直接憤怒，有具體指責（電價漲三次）
   → 推噓：噓多或推多皆可能（推=認同批評）

2. 「民進黨執政八年，年輕人買不起房、薪水沒漲，還好意思說經濟好」
   → 語氣：具體數據式批評
   → 推噓：推多（認同批評）

3. 「政府對美伊戰爭的應對太慢了，油價都漲上天了才出來講話」
   → 語氣：針對具體事件的即時批評
   → 推噓：混合

## 反串支持政府範例
1. 「民進黨執政太讚了！台灣經濟要起飛了！繼續執政一百年！」
   → 語氣：誇張到不合比例的正面
   → 關鍵：「一百年」暴露反諷意圖
   → 推噓：推多（推=認同反串）

2. 「推，政府做得真好，物價只漲了一點點而已嘛，不要太貪心」
   → 語氣：故意輕描淡寫嚴重問題
   → 關鍵：「一點點」「不要太貪心」= 諷刺

3. 「賴清德比蔣經國還偉大！台灣有救了！」
   → 語氣：不合理的誇張比較
   → 關鍵：比較對象太誇張 = 明顯反串

## 常見反串關鍵詞
- 「讚讚讚」「超棒的」「繼續執政」（過度正面時）
- 「笑死」「可憐哪」「嘻嘻」（搭配看似支持的內容）
- 「真香」「躺平」（嘲諷性認命）
- 「不愧是」「果然是」（前面加負面事件時 = 反諷）
