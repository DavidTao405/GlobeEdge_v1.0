# dim1 制度公信力 — PTT 語境知識

## 台灣在地術語
- 「恐龍法官」：嘲諷判決不合常理的法官
- 「司法迫害」：認為司法被政治利用（常見於柯文哲案討論）
- 「法院認證」：反諷用法，如「法院認證的貪污犯」
- 「黑箱」：指立法過程不透明
- 「表決部隊」：嘲諷立法院多數暴力

## 真誠討論制度範例
1. 「柯文哲案的量刑跟其他貪汙案比起來是否合理？趙藤雄那邊判多少？」
   → 語氣：比較性分析，引用具體案例
2. 「立法院這次的修法程序有沒有完成委員會審查？」
   → 語氣：程序性質疑，關心制度本身
3. 「判決書公開後大家可以看看法官的理由是否成立」
   → 語氣：理性，願意看證據

## 反串範例
1. 「法院認證清白，大家可以散了，台灣司法超棒der」
   → 「超棒der」= 明顯反諷
2. 「推，司法獨立大家都知道，法官從來不看顏色辦案」
   → 語氣平靜但內容與普遍認知矛盾 = 反諷
3. 「17年剛好而已，應該判更重，最好無期，笑死」
   → 「笑死」暴露非真誠的極端化

## 反串關鍵詞
- 「法院認證」（後接正面評價時 = 反諷）
- 「司法獨立（笑）」
